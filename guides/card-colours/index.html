How to colour cards in Jira Cloud

Card colours make a board readable from across the room: blocked work in red, bugs striped, your own cards picked out. Jira Cloud has a native option, but only on some boards.

What Jira lets you change

On a company-managed board, a board admin can open Board settings → Card colours and colour the left edge of cards by issue type, priority, assignee or a JQL query. It's one stripe, one method per board, and nothing tints the whole card.

On a team-managed board there are no card colours at all.

With Tintboard for Jira

  1. Install Tintboard for Jira from the Atlassian Marketplace (free for up to 10 users).
  2. Open Settings → Apps → Tintboard → Card rules and click + Add card rule, or one of the common rules: Blocked, Overdue, Due this week, My cards, Untouched for a week, Bugs.
  3. Build the rule as a sentence: When label is blocked and priority is Highest, show whole card tint in red, on all boards. A preview shows the card as it will look.
  4. Save. Install the Tintboard browser extension, or let IT install it for everyone.

Rules are checked from the top and the first one that matches colours the card, so put the most important ones first.

What a rule can test

Condition Example
Label, status, priority, issue type Label is blocked
Component Component is Backend
Parent or epic Parent is MOB-12 or Payments revamp
Summary contains Summary contains [hotfix]
Assignee Assignee is Sam, or "assigned to the person looking"
Dates Due date has passed, due within 7 days, not updated for 14 days

Rules work the same on company- and team-managed boards and in the backlog. A Colours button on each board explains every colour to new teammates. Get started.
