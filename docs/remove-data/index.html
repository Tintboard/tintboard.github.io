Remove Tintboard's data from your site

Uninstalling Tintboard deletes its Forge storage (your rules and settings). Two kinds of small properties stay in your own Jira and Confluence until an admin deletes them. Neither is ever sent anywhere else.

Property Where What it holds
tintboard.published Each Jira project and each Confluence space A signed copy of your colour rules or reading defaults, and the licence state. No personal data
tintboardseen Each user's Jira profile, for users who had the extension At most 5 week numbers, such as 2026-W45

You need a Jira and Confluence admin account and an API token. In the commands below, replace your-site, you@example.com and API_TOKEN.

Jira projects

List the projects, then delete the property from each one:

curl -s -u you@example.com:API_TOKEN "https://your-site.atlassian.net/rest/api/3/project/search?maxResults=100" | jq -r '.values[].key'
curl -s -u you@example.com:API_TOKEN -X DELETE "https://your-site.atlassian.net/rest/api/3/project/PROJECT_KEY/properties/tintboard.published"

Confluence spaces

List the spaces with their IDs, find the property's ID in each, then delete it:

curl -s -u you@example.com:API_TOKEN "https://your-site.atlassian.net/wiki/api/v2/spaces?limit=250" | jq -r '.results[] | "\(.id) \(.key)"'
curl -s -u you@example.com:API_TOKEN "https://your-site.atlassian.net/wiki/api/v2/spaces/SPACE_ID/properties?key=tintboard.published" | jq -r '.results[].id'
curl -s -u you@example.com:API_TOKEN -X DELETE "https://your-site.atlassian.net/wiki/api/v2/spaces/SPACE_ID/properties/PROPERTY_ID"

User profiles

Jira's user search finds users by one week number at a time. Search each of the last five weeks (ISO week numbers, such as 2026-W45), then delete the marker from each user found:

for week in 2026-W45 2026-W44 2026-W43 2026-W42 2026-W41; do
  curl -s -u you@example.com:API_TOKEN -G "https://your-site.atlassian.net/rest/api/3/user/search/query" \
    --data-urlencode "query=[tintboardseen].w is \"$week\"" --data-urlencode 'maxResults=100' | jq -r '.values[].accountId'
done | sort -u
curl -s -u you@example.com:API_TOKEN -X DELETE "https://your-site.atlassian.net/rest/api/3/user/properties/tintboardseen?accountId=ACCOUNT_ID"

Markers older than five weeks can only remain on profiles of people who stopped using the extension; you can delete them the same way if you know the account.

People can also remove the extension from their browser, which stops any new marker being written.
