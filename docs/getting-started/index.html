Get started with Tintboard

Tintboard has two parts: an app that your Jira or Confluence admin installs from the Atlassian Marketplace, and a free browser extension that shows the colours and reading settings to everyone. Setup takes about five minutes.

1. Install the app

In Jira, go to Apps → Explore more apps, search for Tintboard for Jira and install it. For Confluence, install Tintboard for Confluence the same way. Both are free for up to 10 users.

2. Choose your colours (Jira)

Open Settings → Apps → Tintboard. The Overview tab has three ready-made schemes (Scrum basics, Support team, Bugs first): one click fills everything in, and you can change any of it before saving.

  • Colours tab: colours for labels and statuses (your site's own names are suggested), for board columns, with an optional card limit that turns the column title red, and for swimlanes when a board is grouped (by an assignee's name, an epic, "Unassigned"…). Pick from the Tintboard palette or the colour-blind-safe palette, or enter any hex colour; colours that would make label text hard to read can't be picked.
  • Card rules tab: a rule colours a whole card (tint) or its left edge (stripe) when all its conditions match: label, status, priority, issue type, component, parent or epic, summary text, assignee or "assigned to the person looking", or a due or last-updated date. Rules are checked from the top and the first match wins. Each rule applies to all boards or the ones you choose.
  • Colours for one project: above the Colours and Card rules tabs, Colours for switches from All projects to one project. What you set there adds to the colours for all projects: an entry with the same name wins, and the project's card rules are checked first. Boards and searches that mix projects show each issue in its own project's colours.
  • Board & issue view tab: fields on cards (up to 3 per board, such as story points, a sprint, components or any custom field, shown in a line at the bottom of each board card, on team-managed boards too), the board's Colours legend button, and the issue view default: a narrower details panel, or hide it and keep only the status. Each person can change this for themselves.
  • Backup tab: export your colours, or import them from another site.

Click Save, at the top of the page. People see the change the next time they load a Jira page. If something needs fixing first, the page says what and where.

3. Set reading defaults (Confluence)

Open Confluence settings → Tintboard reading comfort. Set a site default for text size, line spacing and reading width, and space defaults for spaces that need something different. Under Code blocks, pick a colour theme for code on every page (Paper, Mint, Night, Ocean or High contrast, all readable to WCAG AA). Each reader can still choose their own reading settings and code theme in the extension.

4. Install the extension

Each person needs the Tintboard extension for Chrome, Edge or Firefox. To install it for everyone at once, follow the IT deployment guide. Otherwise, share the store links shown on the app's settings page.

5. Check it works

Open a board. The Tintboard icon in the browser toolbar shows:

Badge Meaning
none Active: your team's colours are on
? No rules found for this site yet: an admin hasn't saved any, or the app isn't installed
! The site's Tintboard licence has lapsed
off Safe mode is on for this site

On the Jira settings page, admins can see how many people used the extension in the last 5 weeks. While fewer than 80% of people have it, every tab says so, with a message ready to paste into your team chat. People without the extension see where to get it under the colour legend in each issue.

If something looks wrong

Click the Tintboard icon and tick Safe mode to turn everything off on that site, then tell us at support. When Atlassian changes a page, Tintboard switches the affected colours off instead of showing something broken, and we ship a fix within 2 business days.
