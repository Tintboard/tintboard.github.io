为 Jira 看板上的卡片着色

简短回答： 在公司管理的看板上，打开 看板设置 → 卡片颜色，可按事务类型、优先级、经办人或 JQL 查询为卡片着色：Jira 会在每张卡片左边缘画一条色条。团队管理的看板没有卡片颜色。Tintboard for Jira 在两种看板上都增加了卡片颜色规则，包括为整张卡片着色。

彩色卡片让看板远远一看就清楚：受阻的工作显示红色，缺陷带色条，自己的卡片突出显示。Jira Cloud 有原生选项，但并非所有看板都能用。

Jira 本身能做什么

在公司管理的看板上，看板管理员可以打开 看板设置 → 卡片颜色，按事务类型、优先级、经办人或 JQL 查询为卡片左边缘着色。只有一条色条，每个看板只能用一种方式，整张卡片不会着色。

在团队管理的看板上，完全没有卡片颜色。

使用 Tintboard for Jira

  1. 从 Atlassian Marketplace 安装 Tintboard for Jira（最多 10 位用户免费）。
  2. 打开 设置 → 应用 → Tintboard → Card rules 添加规则，或从现成的规则开始：Blocked、Overdue、Due this week、My cards、Untouched for a week、Bugs。
  3. 像写句子一样构建规则：当 标签为 blocked 且 优先级为最高 时，在 所有看板 上 显示 红色的 整卡着色。预览会显示卡片的实际效果。
  4. 保存后安装 Tintboard 浏览器扩展，或让 IT 为所有人部署。

规则从上到下读取，第一条匹配的规则决定卡片颜色，所以请把最重要的放在最前面。规则可以检查标签、状态、优先级、类型、组件、父级或史诗、摘要、经办人或日期（已逾期、7 天内到期、14 天未更新）。在公司管理和团队管理的看板以及待办事项中效果相同。Tintboard 中文。
