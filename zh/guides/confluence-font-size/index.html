如何更改 Confluence Cloud 的字号

简短回答： Confluence Cloud 没有字号设置。每位读者可以用浏览器缩放（Ctrl 或 Cmd 加 +），但这会放大所有内容；作者可以把页面设为全宽，这改变的是行长而不是字号。若要为整个站点或某个空间设置字号、行距和阅读宽度，管理员可以使用 Tintboard for Confluence，每位读者仍可选择自己的设置。

Confluence Cloud 没有字号设置：所有读者看到的字号和行距都一样。如果长页面让读者疲劳，或者有读者视力较弱或有阅读障碍，可以考虑以下方法。

Confluence 和浏览器本身提供什么

  • 页面宽度：编辑页面的人可以把页面设为固定宽度或全宽（编辑时的 ↔ 按钮）。这改变的是行长，不是字号。
  • 浏览器缩放：每位读者可以按 Ctrl 加 +（Mac 上为 Cmd 加 +）。所有内容都会变大，包括菜单和侧边栏，而且每台设备都要重新设置。
  • 编辑器中的标题和文本样式只改变页面的一部分，不改变默认阅读字号。

想找到最舒适的字号、行距和宽度，可以用免费的 Confluence 阅读舒适度预览（英文）在示例页面上试一试。

使用 Tintboard for Confluence

  1. 从 Atlassian Marketplace 安装 Tintboard for Confluence（最多 10 位用户免费）。
  2. 打开 Confluence 设置 → Tintboard reading comfort。设置站点默认值：字号（14 到 20 px）、行距（1.4 到 2.0）和阅读宽度；需要不同设置的空间可以单独设置空间值。
  3. 安装 Tintboard 浏览器扩展，或让 IT 为所有人部署。

之后，所有页面和博客文章都会以这些设置显示，浅色和深色主题均适用。每位读者仍可通过扩展按钮选择自己的字号、行距和宽度，并以读者自己的选择为准。页面内容本身永远不会改变。Tintboard 中文。

不是管理员？ 请管理员安装：一条可直接发送的消息（英文）。
